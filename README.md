# Open OSINT Desk

**Open knowledge. Verified information. Responsible research.**

An open, free and community-driven OSINT learning and research resource. This repository contains an educational starter kit for responsible research using publicly available sources.

The resource lists are starter material, not endorsements or certifications. Verify current access, coverage, limitations and terms before relying on any tool or source. The project does not support doxxing, targeting, unauthorized access or publishing sensitive personal information.
