# Report templates

## Short situation report

```markdown
# Situation report — [TOPIC]
**As of:** YYYY-MM-DD HH:MM UTC (or specify timezone)
**Research window:** [FROM — TO]

## Executive summary
[3–5 concise sentences]

## Confirmed facts
- [Claim] — [source, date, URL]

## Attributed statements
- [Who said what] — [original source]

## Assessment
[Reasoned interpretation, with evidence and caveats]

## Hypotheses
- [Hypothesis] — confidence: low / moderate / high; rationale

## Unknowns and contradictions
- [What is not established]

## Indicators to monitor
- [Public, non-tactical indicator]

## Sources
1. [Publisher, title, date, URL]
```
