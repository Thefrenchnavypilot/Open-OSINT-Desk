# Contributing

Thank you for helping improve Open OSINT Desk. Contributions can include tool listings, source references, translations, corrections, exercises and methodology improvements.

## Before submitting

- Check whether the resource already exists.
- Prefer the official project or provider URL.
- Verify that the resource is publicly accessible and describe any registration or payment requirements.
- Do not copy copyrighted content; summarize in your own words and link to the original.
- Do not include personal data, private information, credentials or sensitive operational details.
- Be transparent about uncertainty and limitations.

## Tool entry format

Use this template:

```markdown
### Tool name
- **URL:**
- **Category:**
- **Purpose:**
- **Access:** Free / Freemium / Paid
- **Registration:** Required / Optional / Not required
- **Coverage:**
- **Limitations:**
- **Last checked:** YYYY-MM-DD
- **Notes:**
```

## Source entry format

For datasets and publications, include publisher, scope, methodology link, update frequency, known biases or gaps, access conditions and last verification date.

## Pull request checklist

- [ ] The URL is correct and preferably official.
- [ ] The description is factual and neutral.
- [ ] Access and pricing labels were checked.
- [ ] Limitations and geographic coverage are stated where known.
- [ ] No private personal data or unsafe operational details are included.
- [ ] Copyright and attribution requirements are respected.

By contributing, you agree that your contribution may be distributed under the repository's stated license.
